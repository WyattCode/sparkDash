# sparkDash 核心更新与迁移交接

本次更新位于 WyattCode/sparkDash 的 feat/zh-ui-hardening-20260914 分支，基于远端提交 897d9b6。选择性提取 MiaAI-Lab/sparkDash 上游 main 606e0f39fdf6c02f58bf4387ce7e2ecc14d774c5 的核心修复，保留现有汉化和定制源码。应用版本号仍为 1.8.6，不代表已整体升级到上游 2.0。

## 已完成的更新

- SSH：实际采集命令和连接 readiness 共用凭据隔离的私有 socket；SSH_CONTROL_PERSIST_SECONDS 优先，兼容 SSH_CONTROL_PERSIST，0 禁用复用。
- 离线：远程节点离线暂停自动域采集；在线探测按 5/15/30/60 秒退避，连续鉴权失败第 5 次起使用 15 分钟兜底。恢复、编辑配置或重新启动监控后恢复常规周期。
- 流式响应：正确处理 SSE 的 CRLF 以及跨数据块分割，保留既有 Token 解析逻辑。
- 安全：补齐 IPv4-mapped IPv6 目标校验、SSH 用户校验、回环绑定的 Host/Origin 检查、原生 WebSocket URL token 解析。变更连接目标时清除受影响的旧凭据，配置和 secrets 保存失败保持旧状态；新密码随配置保存，失败保留表单草稿。节点仅修改 isLocal 也执行目标校验。
- SGLang：实时 decode gauge 优先于累计差分，保留可选信息的短超时和退避、独立 load 读取、computed/cache prefill 分离及 served model ID。详情页新增 KV 占用、KV 缓存池与权重驻留。
- Token 台账：首页底部默认折叠，支持今日、近 7 日、近 30 日及累计观测；输入、缓存命中与输出分开显示。
- 能耗：多个主节点/独立端口分别计数，工作节点排除；覆盖率读取服务端窗口。集群范围变化前归档旧历史，归档失败不覆盖原文件，同名归档不丢失。
- 界面源码：同步 DGX Spark 首页、全页流光与进度条变化动画、移动端节点名称/内存换行修复，以及展示名称首字母大写。左上角 Logo 保留 sparkDash，原始节点 ID、路由和配置不改名。尊重 reduced-motion。
- 并发测试：采用上游 32 个不同代码任务，单路 binary_search，预热 warmup_noop；新旧任务成绩不宜直接比较。本次未运行真实模型压测。

## 指标口径与数据保存

Token 台账目前仅接入 SGLang。每 15 秒读取已有采集快照，不增加模型 API 调用；约每 30 秒及正常关闭时保存 config/llm-token-totals.json，权限 0600、原子替换。按 UTC 自然日统计，保留 35 天日桶，累计观测保留；默认折叠时前端不轮询台账。

只累计启用后观测的计数增量。首次采样、进程重启、离线/过期、模型或来源改变、计数回退及过长缺口均重建基线，不导入旧引擎累计值或补算未知区间。基线不写入磁盘。工作节点不重复计数；TP/PP/EP 副本取最大，独立流式/非流式及 DP 标签组相加。缓存命中属于输入的一部分，不额外相加；缺失计数显示“—”。输入可能包含缓存命中 Token，与“实际计算的预填充吞吐”口径不同。

KV 容量和权重驻留来自引擎单调度实例报告，不能当作四机总量或与共享内存相加。报告容量为 0 时按未提供显示“—”；采集失败不保留旧字段冒充新数据。

能耗仍沿用 GPU/CPU 推算整机功耗的估算模型。非 SGLang 后端保留原输出累计计数路径；SGLang 缺失新计数时不使用残留旧总值。在有 telemetry 信息时要求 LLM 样本不超过 10 秒且不来自未来。端口离线、无效、不可用或过期立即清除基线，恢复首帧不补记。效率仅使用开始跟踪 Token 后的能耗窗口；适用于观测，不用于计费。

config/fleet-energy.json、config/llm-token-totals.json、范围归档、连接日志、secrets 和节点配置不得作为代码提交。读取到损坏 Token 历史时停止覆盖原文件；保存失败提示并保留待写状态重试。正常关闭保存失败以非零退出标记。

## 迁移与回退

1. 备份目标设备的 config/、加密密钥、SSH 配置、服务配置和 dist，并限制备份访问权限；不要上传这些备份。
2. 从本功能分支取得代码，在独立目录安装依赖并运行类型检查、后端和前端测试。保留节点、模型、网络、鉴权、采集频率与运行方式的现场配置。
3. 在临时输出目录构建，检查目标设备的主题与布局。本提交没有修改 Compose、安装 manifest、启动频率或节点配置。公开版仍保留 SPARKDASH_VERIFICATION_NODE/CONTAINER/IMAGE 的显式配置约定。
4. 看板没有运行中的测试任务后，仅发布/重启看板，检查 API、WebSocket、每个节点的数据新鲜度、模型服务身份、KV 字段、台账与能耗。监控更新不需要重启模型。
5. 回退保留 config/ 数据，撤回本提交代码并恢复之前的前端资源；Docker 挂载 server 源码时，换镜像不会回退后端源码。

不要从包含现场私密配置的工作树直接推送。此提交未包含生产 Compose、私有控制中心接入、私有交接、截图、运行数据或密钥；保留远端已有内容。
