# DGX 工作区、暖金色界面与交互更新

## 更新内容

- 全局任务导航统一为概览、模型服务、节点监控、测试工具、运行分析和诊断。避免重复 Tab 与指标堆叠，直接链接和浏览器返回可用。
- 首页模型信息、缩小的原四机装饰、关键指标及等高节点卡片；服务详情入口、设备切换、排序和筛选保持独立分工。
- 暖金属金色用于交互与正常数据；绿色保留在线/成功，警告和危险状态不覆盖。白色/暖米色/暗色/OLED 各自背景保留，弹窗共享主题表面。
- 实时图采用单调平滑曲线和有界过渡，悬停显示曲线上的圆点、细参考线与真实采样读数。保留普通鼠标箭头；低动态、隐藏、离屏与卸载停止不必要动画。
- 最近两分钟数值历史在同源浏览器有界保存，刷新后续接。不会补造关页期间的采样，不是永久服务器历史；过期缓存和首次使用仍需积累。模型身份改变或节点删除清理不匹配历史。
- 修复窄屏设备详情的中文标签竖排、缩小后的悬停点定位、浮层限位与滚动残留、历史低值重复刻度、曲线侵入坐标区、非法进度条宽度，以及开关和危险按钮的文字/控件对比。
- SGLang 从已有 server-info 读取真实 TP/EP，用于只读显示；不按机器数量猜测，也不改引擎配置。

## ATOM 文件与 DGX 图标

已有 ATOM 的 public/atom-*、public/icons/、index.html、默认 manifest、config/settings.json、deploy/ai-top-atom/ 和交接文件未覆盖。旧前端归档及校验清单保持原样，本次源码更新不表示那份归档包含新代码，也不表示另一台设备已经部署。

新 DGX 图标位于 public/dgx-gold/。需要 React 工作区及其暖金色 Logo 配套图标时，在隔离部署目录显式选择：

```bash
node scripts/use-dgx-gold-brand.mjs --apply
npm run build
```

脚本只改 index.html 的四个品牌元数据/资源引用；不改原 ATOM 图标或归档。不要在生产目录未经备份运行。未开启此选项时，公开入口仍保留原 ATOM 图标/元数据，这是兼容保留，不是新版 DGX 图标缺失。恢复 ATOM 原归档仍遵守旧交接；完整 ATOM 品牌回迁到新 React 工作区需另行视觉验收。
