# 简体中文界面与稳定性改进

本分支包含简体中文界面、四主题一致性、模型服务控制台、诊断导出和交互稳定性修复。

- 统一概览与机器页面、字体、强调色及手机布局。
- 模型服务标题改为紧凑信息栏，验收与请求详情默认折叠；保留异常和过期提示。
- 首页品牌入口执行完整刷新；启动时提前恢复主题，避免初始错误页面闪现。
- 浏览器存储不可用时安全降级；非法路由编码不再导致页面崩溃；旧设置响应不能覆盖新保存结果。
- 编辑和移除流程增加异步状态隔离、确认与错误处理；诊断导出采用匿名字段白名单。
- 容器镜像不包含运行配置或凭据。部署时使用自己的运行配置和挂载，不上传密钥、密码或现场采集记录。

验证：脱敏版本的类型检查、356 项后端测试、82 项前端测试及生产构建通过（共 438 项测试）。脱敏前版本另有四主题、桌面和手机浏览器复核；脱敏版本未重新部署到生产或进行浏览器视觉验收。

注意：服务验收适配含双节点部署约定，并非对任意模型环境的全面兼容承诺。启动预热记录尚未自动导入，历史记录不代表当前启动验收；关机操作要求部署方提供既有脚本并通过就绪检查。本变更不安装无人值守恢复任务，也不更改模型性能参数。

本分支基于本机已验证的 f035ca2；上游后续提交尚未合并。现场截图、私有交接资料、本机 SSH 挂载和用户设置不包含在此提交中。

## 部署标识脱敏

- 不包含部署机器的用户名路径、节点主机名、容器名或 Grafana 看板 UID。
- 验收适配器通过私有 `.env` 中的 `SPARKDASH_VERIFICATION_NODE`、`SPARKDASH_VERIFICATION_CONTAINER`、`SPARKDASH_VERIFICATION_IMAGE` 配置，compose 已转发这些变量。节点名必须唯一匹配本机 Head；容器用于只读启动标识查询；图片须为容器内可读的纯红色 JPEG。不要将真实值提交到仓库。
- 该适配器仍限定模型别名 `deepseek-v4-flash-vision-exp` 和本机端口 8888，并未扩展到任意模型；未配置节点时不探测，启动标识或图片缺失时不发送生成请求。
- 历史曲线按 `role=worker` 区分工作节点，不再识别特定主机名；Grafana 链接打开同主机 3000 端口首页，由使用者选择自己的看板。
- 公开分支的脱敏不意味着本机生产自动换版；已有部署需要显式配置后另行验证上线。
